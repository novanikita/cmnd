# Preview по секретной ссылке

Черновики лежат в `preview/<токен>/`. Без токена в URL страницы не найти.

**Ссылка для клиента:** `https://flowerdog.studio/preview/<токен>/`

Токен задаётся в [`pages.json`](pages.json) (`token`).

## Как это устроено

- Исходники черновиков лежат в корне репозитория (`yandex.html`, `sporos.html`, …) — там их удобно редактировать.
- При публикации сайта (`scripts/build-production.sh`) эти файлы **исключаются из корня** опубликованного сайта, поэтому `flowerdog.studio/yandex.html` отдаёт 404 и не индексируется.
- Опубликованы только их копии в `preview/<токен>/` — по неугадываемой секретной ссылке, с `noindex` и `Disallow: /preview/` в `robots.txt`.

## Добавить страницу в превью

1. Создай или обнови HTML в корне репозитория (`sporos.html`, `dodo.html`, …).
2. Добавь запись в `pages.json`:

```json
{
  "file": "my-project.html",
  "titleRu": "Название",
  "titleEn": "Title"
}
```

3. Добавь имя файла в список исключений в [`scripts/build-production.sh`](../scripts/build-production.sh) (`--exclude '/my-project.html'`), чтобы он не попал в корень опубликованного сайта.
4. Пересобери превью:

```bash
bash scripts/sync-preview-pages.sh
```

5. Закоммить `preview/<токен>/` вместе с изменениями.

## Опубликовать черновик (вынести из превью на сайт)

1. Убери файл из списка `--exclude` в `scripts/build-production.sh`.
2. Убери запись из `pages.json` и (по желанию) удали копию из `preview/<токен>/`.
3. Поставь ссылку на страницу в `js/projects-data.js` / на индексе.

## Сменить секретную ссылку

1. Поменяй `token` в `pages.json` (например `x9m4-b2k8-q1wn`).
2. Запусти `bash scripts/sync-preview-pages.sh`.
3. Удали старую папку `preview/<старый-токен>/`.
4. Отдай клиенту новый URL.

## Важно

- Это **не** настоящий пароль: кто знает прямой URL файла в `preview/<токен>/`, откроет страницу. Защита — в неугадываемом токене.
- Копии в `preview/<токен>/` используют `<base href="../../">` — css, js, картинки и partials грузятся с основного сайта. Переходы между черновиками ведут внутрь папки токена (`SITE_PROJECT_LINK_PREFIX` для портфолио, прямые ссылки в хабе).
- В корне опубликованного сайта черновиков **нет** — они исключены в `build-production.sh`, поэтому по прямому URL вида `/yandex.html` отдаётся 404.
- `robots.txt` закрывает `/preview/` от индексации; на каждой preview-странице стоит `noindex`.
