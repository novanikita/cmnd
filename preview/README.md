# Preview по секретной ссылке

Черновики лежат в `preview/<токен>/`. Без токена в URL страницы не найти.

**Ссылка для клиента:** `https://flowerdog.studio/preview/<токен>/`

Токен задаётся в [`pages.json`](pages.json) (`token`).

## Добавить страницу в превью

1. Создай или обнови HTML в корне репозитория (`sporos.html`, `dodo.html`, …).
2. Добавь запись в `pages.json`:

```json
{
  "file": "my-project.html",
  "titleRu": "Название",
  "titleEn": "Title"
}
```

3. Пересобери превью:

```bash
bash scripts/sync-preview-pages.sh
```

4. Закоммить `preview/<токен>/` вместе с изменениями.

## Сменить секретную ссылку

1. Поменяй `token` в `pages.json` (например `x9m4-b2k8-q1wn`).
2. Запусти `bash scripts/sync-preview-pages.sh`.
3. Удали старую папку `preview/<старый-токен>/`.
4. Отдай клиенту новый URL.

## Важно

- Это **не** настоящий пароль: кто знает прямой URL файла в `preview/<токен>/`, откроет страницу.
- Копии в `preview/<токен>/` используют `<base href="../../">` — css, js, картинки и partials грузятся с основного сайта.
- Страницы в **корне** (`sporos.html` и т.д.) по-прежнему доступны по прямому URL, если их не убрать. Для полной изоляции держи черновик только в превью или не коммить корневой файл до публикации.
- `robots.txt` закрывает `/preview/` от индексации; на каждой preview-странице стоит `noindex`.
